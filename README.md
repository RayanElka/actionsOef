# Repository Visualizer Exercise

A school exercise with GitHub Actions workflows that generate a diagram of the repository. The sample website lives in `OneDrive/Documenten/AP23-24/actions oef/`. It contains a static bird catalogue with its own scripts, styles and images.

The workflow definitions are in `.github/workflows/`. For an overview of the developer projects I show in my portfolio, see my [portfolio site](https://portofolio-five-amber.vercel.app).
